# 📊 Credit Risk & Loan Default Analysis

## 📌 Project Overview

This project presents an interactive Credit Risk and Loan Default Analysis dashboard built using Microsoft Power BI.

The dashboard analyzes loan default patterns and identifies how different borrower and loan characteristics are associated with default risk.

## 🎯 Objectives

- Analyze overall loan default rates
- Identify borrower segments with higher default risk
- Compare default rates across different categories
- Present key credit-risk insights through an interactive dashboard

## 📊 Dashboard

The Power BI dashboard contains two pages:

### 1. Main Dashboard

Provides a high-level overview of loan performance through:

- Total Defaults
- Default Rate
- Total Loans
- Average Loan Amount
- Loan Default Distribution
- Default Rate by Employment Type
- Default Rate by DTI Group
- Default Rate by Loan Purpose
- Default Rate by Credit Score Group

### 2. Detailed Analysis

Provides deeper analysis using interactive slicers and visualizations for:

- Employment Type
- Loan Purpose
- Credit Score Group
- DTI Group
- Interest Rate Group
- Education
- Marital Status

## 🔍 Key Analysis Areas

- Credit Score and default risk
- Debt-to-Income (DTI) and default risk
- Interest Rate and default risk
- Employment type and default rate
- Loan purpose and default rate
- Borrower demographic characteristics

## 🛠️ Tool Used

- Microsoft Power BI

## 📁 Project File

The `.pbix` file contains the complete interactive Power BI dashboard.

## 💡 Key Takeaway

The dashboard helps identify patterns in loan defaults across borrower characteristics and loan-related factors, providing a clear and business-friendly view of credit risk.
